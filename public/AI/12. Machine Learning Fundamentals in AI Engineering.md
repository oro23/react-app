# Machine Learning Fundamentals in AI Engineering

**Machine Learning (ML)** is a branch of Artificial Intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

In AI engineering, understanding ML fundamentals helps engineers choose the right models, prepare data, evaluate performance, and integrate machine learning capabilities into real-world applications.

------

# What is Machine Learning?

Traditional programming:

```
Rules + Data
      ↓
Program
      ↓
Output
```

Machine Learning:

```
Data + Expected Results
          ↓
     Learning Algorithm
          ↓
        Model
          ↓
   New Data → Prediction
```

Instead of manually writing every rule, ML algorithms discover patterns from examples.

------

# Example: Email Spam Detection

Traditional approach:

```
IF email contains "win money"
THEN spam
```

This fails because spam patterns constantly change.

Machine learning approach:

```
Thousands of emails
        ↓
ML algorithm learns patterns
        ↓
Spam detection model
        ↓
New email → Spam / Not Spam
```

The model learns signals such as:

- Words used
- Sender behavior
- Email structure
- Links
- Frequency patterns

# 2. Features

Features are the input variables used by a model.

Example: Predicting house prices.

Features:

```
House size
Number of bedrooms
Location
Age of house
```

Output:

```
House price
```

The quality of features strongly affects model performance.

------

# 3. Labels

A label is the target output the model tries to predict.

Example:

Input:

```
Image of a dog
```

Label:

```
Dog
```

In supervised learning, models learn from examples with known labels.

# 1. Supervised Learning

Supervised learning trains models using labeled data.

```

```


## Types of Supervised Learning

## A. Classification

Predicts categories.

Examples:

- Spam detection
- Disease diagnosis
- Image recognition
- Sentiment analysis

Output:

```
Positive
Negative
Neutral
```

------

## B. Regression

Predicts continuous values.

Examples:

- House prices
- Stock prices
- Sales forecasting
- Temperature prediction

Output:

```

```

# Common Supervised Learning Algorithms

## Linear Regression

Used for predicting numerical values.

Example:

```
House size → House price
```

------

## Logistic Regression

Used for classification.

Example:

```
Email → Spam or Not Spam
```

------

## Decision Trees

A model that makes decisions using rules.

Example:

```

        |
       Yes
        |

```

------

## Random Forest

Combines multiple decision trees for better accuracy.

Used for:

- Classification
- Regression

------

## Support Vector Machines (SVM)

Finds boundaries separating different categories.

------

## Neural Networks

Inspired by biological neurons.

Used heavily in:

- Deep learning
- Computer vision
- NLP
- Generative AI

# 2. Unsupervised Learning

Unsupervised learning works with unlabeled data.

The model discovers hidden patterns.

Example:

```
Customer data

↓

Find groups of similar customers
```

------

## Common Unsupervised Learning Tasks

## Clustering

Groups similar data points.

Example:

Customer segmentation:

```
Group 1:
Young customers

Group 2:
High-value customers

Group 3:
Occasional buyers
```

Algorithm:

- K-Means
- DBSCAN
- Hierarchical clustering

------

## Dimensionality Reduction

Reduces the number of variables while preserving important information.

Uses:

- Visualization
- Faster training
- Feature compression

Algorithms:

- PCA
- t-SNE
- UMAP

------

# 3. Reinforcement Learning

Reinforcement learning involves an agent learning through interaction with an environment.

The agent:

1. Takes an action.
2. Receives feedback.
3. Learns from rewards or penalties.

Example:

```
Robot

Action:
Move forward

Reward:
Reached target

Penalty:
Hit obstacle
```

# Model Training

Training means adjusting model parameters to reduce errors.

Example:

A model predicts:

```
Actual price:
$500,000

Prediction:
$450,000
```

------

# Loss Function

A loss function measures how wrong the model is.

Example:

Prediction error:

```
Actual:
10

Predicted:
8

Error:
2
```

Training attempts to minimize this error.

------

# Optimization

Optimization algorithms improve model performance.

Common optimizer:

**Gradient Descent**

It adjusts model parameters step-by-step to reduce error.

------

# Overfitting and Underfitting

## Overfitting

The model memorizes training data but performs poorly on new data.

Example:

Student memorizes answers but cannot solve new problems.

Signs:

- Very high training accuracy
- Poor test accuracy

Solutions:

- More data
- Regularization
- Simpler models

------

## Underfitting

The model is too simple and fails to learn patterns.

Signs:

- Poor training performance
- Poor test performance

Solutions:

- More complex models
- Better features
- Longer training

------

# Model Evaluation

Different tasks use different metrics.

------

## Classification Metrics

### Accuracy

Percentage of correct predictions.

```
Correct predictions / Total predictions
```

------

### Precision

Of predicted positives, how many were actually positive?

Useful for:

- Spam detection
- Fraud detection

------

### Recall

Of all actual positives, how many did we find?

Important for:

- Disease detection
- Safety systems

------

### F1 Score

Balances precision and recall.

------

## Regression Metrics

### Mean Absolute Error (MAE)

Average prediction error.

------

### Mean Squared Error (MSE)

Penalizes large errors more heavily.

------

### R² Score

Measures how well the model explains variation in data.
