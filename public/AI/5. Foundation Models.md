# Foundation Models

**Foundation models** are large AI models trained on enormous amounts of broad, general-purpose data so they can be adapted to many different tasks instead of being built for just one.

Think of them as a **general-purpose engine** rather than a specialized tool. After training once on massive datasets, they can be used directly or customized (through prompting, fine-tuning, or other techniques) for many applications.

### Why are they called "foundation" models?

They serve as the **foundation** for building many AI applications. Instead of training a new model from scratch for every task, developers start with a foundation model and adapt it.

For example, the same model can be used to:

- Answer questions
- Summarize documents
- Translate languages
- Write code
- Analyze images
- Generate images
- Power chatbots
- Search enterprise documents

------

## How they're trained

Foundation models are typically trained in two stages:

### 1. Pretraining

The model learns general patterns from huge datasets.

Examples of training data:

- Books
- Websites
- Scientific papers
- Code repositories
- Images
- Audio
- Videos (for multimodal models)

The model isn't memorizing facts; it's learning statistical patterns, language structure, reasoning patterns, and relationships.

------

### 2. Adaptation

Once pretrained, the model can be adapted using:

- Prompt engineering
- Few-shot learning
- Fine-tuning
- Retrieval-Augmented Generation (RAG)
- Reinforcement Learning from Human Feedback (RLHF)

This is much cheaper than training from scratch.

## Examples

### Language foundation models

These understand and generate text.

Examples include:

- GPT models
- Llama
- Claude
- Gemini
- Mistral

Applications:

- Chatbots
- Coding assistants
- Document summarization
- Translation

------

### Vision foundation models

These understand images.

Applications:

- Medical imaging
- Object detection
- Face recognition
- Image classification

Examples include Vision Transformers (ViT), DINOv2, and Segment Anything (SAM).

------

### Multimodal foundation models

These work with multiple data types simultaneously.

Input:

- Text
- Images
- Audio
- Video

Output:

- Text
- Images
- Speech
- Code

Example tasks:

- "Describe this image."
- "Generate an image from this prompt."
- "Explain what's happening in this video."

------

## Traditional ML vs. Foundation Models

| Traditional Machine Learning       | Foundation Models                                       |
| ---------------------------------- | ------------------------------------------------------- |
| Built for one task                 | General-purpose                                         |
| Needs labeled datasets             | Learns from massive unlabeled or self-supervised data   |
| Train a new model for each problem | Reuse one pretrained model                              |
| Smaller models                     | Very large models (millions to trillions of parameters) |
| Limited transferability            | Can adapt to many tasks                                 |

------

## Why they're powerful

A single foundation model can power many products.

For example, one language model can be used for:

- Customer support
- Email writing
- Code generation
- Legal document analysis
- Medical summarization
- Search
- Research assistants

This flexibility is why foundation models have become central to modern AI development.

## Foundation Models vs. Large Language Models (LLMs)

These terms are related but not identical:

- **Foundation model** is the broader category: a model trained on broad data that can be adapted to many downstream tasks.
- **Large Language Model (LLM)** is a type of foundation model focused primarily on understanding and generating text.

Similarly, image and multimodal models can also be foundation models.

**In short:** every LLM is a foundation model, but not every foundation model is an LLM. For example, a large vision model trained for many image-related tasks is a foundation model without being a language model.
